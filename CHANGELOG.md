# Changelog

## 26.3.14 — 2026-10-14

- Удалён Nekoma's Fixed 0.5.4. Его предметы, блоки и существа больше недоступны.

## 26.3.13 — 2026-10-14

- No Lost Pets заменён на Pet Teleport 2.0.0: возврат питомцев командой /pet.
- Добавлен Inventory Sorting 3.0.1 с настройками из Fabulously Optimized(4): сортировка по ID, двойной щелчок отключён.
- Добавлен Nekoma's Fixed 0.5.4 для Minecraft 26.3.
- Удалён IndyPets (Independent Pets).
- Личные настройки Iris, шейдеров и Euphoria Patcher исключены из публикации.

## 26.3.12 — 2026-10-11

- Отключён Punchy! 2.8e: при активных Iris и Complementary произошёл сбой загрузки текстуры внутри render pass после перезагрузки шейдеров.

## 26.3.11 — 2026-10-11

- Опубликован серверный конфиг IndyPets: домашний радиус питомцев 80 блоков, радиус свистка 96 блоков и стандартное переключение режимов взаимодействием.

## 26.3.10 — 2026-10-11

- Добавлены IndyPets, No Lost Pets и Ride Together для более удобного управления питомцами и совместных поездок.
- Добавлен Sparse Structures: ванильные структуры сохраняют стандартную частоту, а 187 модовых наборов используют коэффициент разрежения 1.7.

## 26.3.9 — 2026-10-11

- Добавлен клиентский мод Punchy! 2.8e, который уже используется в основном Prism-инстансе.
- Опубликованный список модов синхронизирован с текущей сборкой; ранее удалённые Biomes O' Plenty, Terralith, Naturalist и e4mc в неё не возвращались.

## 26.3.8 — 2026-10-11

- Удалены Biomes O' Plenty, Terralith и Naturalist: сборка больше не добавляет новые биомы и животных.
- Вместе с ними удалены ставшие ненужными библиотеки GlitchCore, TerraBlender и Lithostitched.
- Takes a Pillage, приключенческие структуры и End Remastered оставлены без изменений.

## 26.3.7 — 2026-10-10

- Добавлен Just Coordinates для компактного отображения текущих координат игрока.
- Добавлен Structure Explorer с отслеживанием найденных структур и новых экземпляров структур.
- Настройки Distant Horizons скорректированы для более стабильной производительности: снижены дальность и качество LOD, включено отсечение пещер и генерация только чанков.

## 26.3.6 — 2026-10-08

- Добавлены Terralith и Biomes O' Plenty для новой генерации мира; добавлена обязательная библиотека TerraBlender.
- Добавлены Dungeons and Taverns с отдельными улучшениями структур, Towns and Towers, Structory: Towers, Moog's Voyager Structures и Moog's End Structures.
- Добавлены End Remastered, Naturalist и Takes a Pillage вместе с необходимыми библиотеками.
- Совместимость проверена запуском и созданием нового мира: реестры, биомы и структуры загружаются без фатальных ошибок.
- Для этой версии рекомендуется новый мир; изменения генерации появляются только в новых чанках, а удалять Terralith или Biomes O' Plenty из уже созданного мира небезопасно.

## 26.3.5 — 2026-10-08

- `publish.ps1` теперь включает `-XX:+UseZGC` в выбранном Prism-инстансе при наличии Distant Horizons и Java 21+.
- В инструкцию для друзей добавлен обязательный JVM-аргумент ZGC; packwiz не может менять настройки Java в Prism Launcher автоматически.

## 26.3.4 — 2026-10-07

- Удалены все опубликованные ZIP-ресурспаки и профиль Packed Packs `MyVanillaPerfect`.
- Сборка больше не распространяет ресурспаки: пользователи устанавливают их вручную из официальных источников.

## 26.3.3 — 2026-10-07

- Исправлена публикация ресурспаков: Fresh Animations, FA+ Player и FA+ All Extensions теперь входят в индекс packwiz и автоматически скачиваются друзьям.
- Ранее ZIP-файлы присутствовали в Git, но ошибочно исключались из `index.toml` правилами `.packwizignore`.

## 26.3.2 — 2026-10-07

- Заменены дублирующие отдельные FA+ Objects, Creepers, Details и Spiders на единый FA+ All Extensions 1.9.2.
- В профиль Packed Packs добавлены встроенные ресурспаки Continuity и исправлен полный порядок загрузки.

## 26.3.1 — 2026-10-07

- Добавлены девять ресурспаков из отдельного инстанса FO 26.3, включая Fresh Animations и используемые FA+ дополнения.
- Добавлен профиль Packed Packs с тем же приоритетом паков, что и в исходном инстансе.

## 26.3.0 — 2026-10-07

- Новая независимая сборка для Minecraft 26.3.
- Ветка создана с нуля и наполняется только из отдельного инстанса Fabulously Optimized 26.3(1).
